# Blackout — Escape Room Virtual

Trabajo Práctico de Programación I (UADE).

Es la noche del final de Programación I. Se corta la luz en toda la
ciudad y un hombre misterioso te ofrece un trato: resolver una serie de
desafíos para llegar a la facultad a tiempo. Para superar cada obstáculo,
el jugador deberá resolver un Ahorcado y una Mini Batalla Naval antes de
que se agote el tiempo.
